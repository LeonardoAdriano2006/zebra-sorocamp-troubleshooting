**ZebraDesigner 3** é um software de design de etiquetas, tags, recibos e pulseiras com código de barras baseado em Windows que faz parte da suíte de software Zebra DNA. Ele apresenta uma interface intuitiva, estilo Microsoft Office, que permite aos usuários criar etiquetas compatíveis e padrão da indústria rapidamente, eliminando virtualmente a necessidade de conhecimento prévio em código de barras ou treinamento técnico.

A solução está disponível em três edições principais para atender a diversos requisitos de design de etiquetas:

**ZebraDesigner Essentials 3** Esta é a versão gratuita que oferece ferramentas básicas de design e impressão de etiquetas com código de barras. Seus principais recursos incluem:

- Design de etiquetas básicas usando dados fixos ou variáveis.
- Utilização de entrada de teclado, fontes de dados de data, hora e contador.
- Acesso a um assistente de código de barras GS1-128.
- Acesso a modelos de etiquetas pré-projetados ou a capacidade de criar modelos do zero.

**ZebraDesigner Professional 3** Esta edição requer a compra de uma chave de licença de ativação única e oferece um conjunto de ferramentas mais robusto para designs de etiquetas complexos. Seus recursos avançados incluem:

- Capacidades de design e codificação de etiquetas RFID.
- Conectividade de banco de dados com Microsoft Excel, Microsoft Access, arquivos de texto e outros bancos de dados via ODBC.
- Manipulação de dados, concatenação de campos e capacidades de script VB simples.
- Entrada de dados e a capacidade de selecionar registros do banco de dados no momento da impressão.

**ZebraDesigner for Developers 3** Esta é uma edição complementar projetada para desenvolvedores de software criarem e integrarem modelos personalizados de etiquetas e recibos em outras aplicações. Seus recursos incluem:

- Exportação de modelos com comandos de recall ZPL ou XML.
- A capacidade de controlar quais configurações individuais da impressora incluir ou excluir nos modelos.
- Incorporação de RFID em designs de modelos para suportar impressão e codificação RFID.
- Nota: Esta edição não oferece impressão de várias etiquetas de produção diretamente do software.

**Funcionalidades Gerais** Em toda a plataforma, o ZebraDesigner 3 também fornece as seguintes capacidades amplas:

- A interface do usuário pode ser configurada para um de 20 idiomas internacionais.
- Compatibilidade retroativa com formatos de etiqueta criados na versão 2 do ZebraDesigner.
- Suporte para drivers de impressora Windows ZDesigner versão 5 (para compatibilidade com formatos EPL ou CPCL existentes) e drivers de impressora Windows versão 10 (recomendado para criar novos formatos).
