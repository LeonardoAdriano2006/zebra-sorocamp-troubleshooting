## 🛠️ Soluções

### Opção 1 — Utilizar DHCP

Altere o modo de configuração de rede da impressora para **DHCP** ou **Todos**, dependendo do modelo.

Dessa forma, o roteador ou servidor DHCP será responsável por atribuir um endereço IP disponível à impressora.

Após a alteração:

1. Reinicie a impressora, se necessário.
    
2. Verifique o novo endereço IP atribuído.
    
3. Teste a comunicação com o novo IP.
    

### Opção 2 — Definir IP fixo

Caso seja necessário que a impressora mantenha sempre o mesmo endereço IP:

1. Verifique qual é a faixa de IP utilizada pela rede.
    
2. Identifique um endereço IP disponível.
    
3. Configure o IP na impressora.
    
4. Configure corretamente a máscara de sub-rede.
    
5. Configure o gateway, quando necessário.
    
6. Salve as configurações.
    
7. Teste a comunicação com a impressora.
    

> ⚠️ **Atenção:** antes de definir um IP fixo, confirme que o endereço não está sendo utilizado por outro equipamento da rede.
