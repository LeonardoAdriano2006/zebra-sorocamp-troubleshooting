A página de teste do Windows pode ser utilizada para verificar se o computador consegue enviar uma impressão para a impressora.

Esse teste é útil para identificar problemas relacionados a:

- Comunicação entre o Windows e a impressora;
    
- Driver da impressora;
    
- Porta configurada;
    
- Fila de impressão;
    
- Configuração básica da impressora no Windows.
    

> [!NOTE]  
> A impressão da página de teste confirma que o Windows conseguiu enviar um trabalho de impressão para a impressora. Ela não garante que a configuração de etiquetas, o ZPL ou o sistema utilizado para impressão estejam configurados corretamente.

---

## 🪟 Windows 11

1. Abra o **Painel de Controle**.
    
2. Acesse **Exibir impressoras e dispositivos**.
    
3. Selecione **Impressoras e scanners**.
    
4. Selecione a impressora desejada.
    
5. Acesse as **Propriedades da impressora**.
    
6. Clique em **Imprimir página de teste**.

## 🪟 Windows 10

1. Abra o **Painel de Controle**.
    
2. Acesse **Exibir impressoras e dispositivos**.
    
3. Localize a impressora desejada.
    
4. Clique com o botão direito do mouse sobre a impressora.
    
5. Selecione **Propriedades da impressora**.
    
6. Clique em **Imprimir página de teste**.

## 🔎 Resultado do teste

### Página de teste impressa corretamente

Se a página for impressa corretamente, a comunicação básica entre o Windows e a impressora está funcionando.

Caso o problema ocorra somente ao imprimir por um determinado sistema ou aplicação, verifique a configuração desse software.

### Página de teste não foi impressa

Se a página de teste não for impressa, verifique:

- Se a impressora está ligada e pronta;
    
- Se a impressora está conectada ao computador/rede;
    
- Se o Windows reconhece a impressora;
    
- Se a impressora está definida como **online**;
    
- Se existe algum trabalho preso na fila de impressão;
    
- Se o driver está instalado e configurado corretamente;
    
- Se a porta da impressora está correta;
    
- Se existe algum erro apresentado no painel da impressora.
