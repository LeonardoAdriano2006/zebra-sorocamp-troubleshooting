# Calibração manual

## Quando utilizar

Descrever em quais situações esse procedimento deve ser realizado.

## Sintomas

- Impressora não identifica corretamente as etiquetas
- Etiqueta avança várias posições
- Impressão ocorre fora da área correta
- Impressora solicita calibração

## Procedimento

1. Desligue a impressora.
2. ...
3. ...
4. ...

## Resultado esperado

A impressora deve reconhecer corretamente o início e o fim de cada etiqueta.
